# Kowa Bunga University Open Day Website

## Project Overview

The Kowa Bunga University Open Day Website is a static website developed to provide prospective students with information about the  Kowa Bunga University (KBU), located in Queensland, Australia.

The website provides information about the university, its faculties, admission requirements, contact information and the annual Open Day event.

The website was developed using HTML5 and CSS3 and is published online using GitHub Pages.

---

## University Information

**University Name:** Kowa Bunga University (KBU)

**Location:** Queensland, Australia

**Motto:** Learn. Discover. Inspire.

**Open Day:** 10 October 2026

**Open Day Time:** 09:00 - 15:00

> Kowa Bunga University is an university created for this practical assignment. The university information and contact details used on this website are fictional.

## Website Features

The website includes the following pages:

### Home

The Home page introduces Kowa Bunga University and provides:

- University branding and logo
- Welcome message
- Open Day announcement
- Navigation menu
- Featured campus image
- Open Day date, time and venue

### About

The About page provides information about:

- History of Kowa Bunga University
- University vision
- University mission
- Campus information
- University values

### Faculties

The Faculties page provides information about three faculties:

- Faculty of Science
- Faculty of Commerce
- Faculty of Engineering

Each faculty includes information about areas of study and possible career opportunities.

### Admissions

The Admissions page provides information about:

- Admission requirements
- Academic requirements
- English language requirements
- Required documents
- Application process
- Important application dates

### Contact

The Contact page provides:

- Physical address
- Telephone number
- Email address
- Admissions contact information
- Office hours
- Open Day details
- Google Maps link

## Responsive Design

The website uses responsive CSS to improve its appearance and usability on different screen sizes.

Media queries are used to adjust the layout for:

- Desktop computers
- Tablets
- Mobile devices

The navigation menu, faculty sections, information cards and other page elements automatically adjust based on the available screen size.

---

## Running the Website Locally

No database or server-side software is required because the project is a static website.

To view the website locally:

1. Download or clone the project.
2. Open the `UniversityOpenDayWebsite` folder.
3. Open `index.html` using a web browser.
4. Use the navigation menu to move between the different pages.
